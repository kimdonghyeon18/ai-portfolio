# 호텔 예약 취소 분석: 취소율 37%의 원인을 나눠 보고 대응 순서 정하기

> **한 줄 요약:** 예약 119,390건(취소율 37.0%)을 정제한 뒤, 취소와 관련된 요인을 **다른 요인으로 나눠 봐도 방향이 유지되는지** 확인했습니다. 그렇게 걸러낸 다섯 가지 요인을 근거로 호텔별 대응 우선순위를 제안했습니다.

| 항목 | 내용 |
| --- | --- |
| 과제 | 부트캠프 개인 과제 |
| 데이터 | 포르투갈 City Hotel·Resort Hotel 예약 119,390건, 29개 열 |
| 도구 | Python, pandas, matplotlib, seaborn |
| 노트북 | [`hotel_cancellation.ipynb`](./hotel_cancellation.ipynb) |

---

## 1. 문제

- 예약의 **37.0%가 취소**됩니다. 빈방은 그대로 손실이 됩니다.
- 질문: **어떤 예약이 취소되기 쉬운가, 호텔은 무엇부터 바꿔야 하는가?**

## 2. 기획: 분석 전에 정한 것

- **데이터 누수 제외:** `reservation_status`, `reservation_status_date`는 취소 결과 자체를 담은 열이라 분석에서 뺐습니다.
- **연도 비교 안 함:** 2015년과 2017년은 12개월이 모두 있지 않아, 연도별 건수를 비교하지 않았습니다.
- **판단 기준:** 한 요인의 취소율 차이가 **다른 요인으로 나눠 봐도 같은 방향인지**를 확인한 뒤에만 결론으로 삼았습니다.

## 3. 데이터 정제에서 내린 결정

| 발견 | 처리 | 이유 |
| --- | --- | --- |
| `company` 결측 94%, `agent` 결측 14% | 0으로 채우고 경유 여부 열 추가 | 회사·여행사를 거치지 않은 예약으로 해석. 결측 여부에 따라 취소율이 다름(agent 39.0% vs 24.7%) |
| `country` 결측 488건 | `Unknown`으로 유지 | 결측 예약의 취소율이 13.7%로 달라, 정보로 남김 |
| 같은 나라가 `CN` 1,279건 / `CHN` 999건 | `CHN`으로 통일 | 나머지는 모두 3자리 대문자 코드 |
| `meal`의 `Undefined` 1,169건 | `SC`(식사 없음)로 통일 | 같은 의미로 판단 |
| 인원 0명 180건, 성인 10명 이상 이상치 | 제거 | 실제 투숙이 불가능하거나 입력 오류 |
| 0박 715건 | 유지 | 당일 이용일 수 있음 |

## 4. 발견한 요인

| 요인 | 비교 | 다른 요인으로 나눠 확인한 것 |
| --- | --- | --- |
| **예약 시점** | 1주일 이내 9.3% vs 1년 이상 전 **68%** | 예약 경로와 특별 요청 여부로 나눠도 모든 그룹에서 같은 방향 |
| **고객 국가** | 포르투갈 **56.7%** vs 외국 23.6% | 같은 단체 예약 안에서도 포르투갈 84.1% vs 외국 7.2% |
| **예약 경로** | 단체 61.1%, 온라인 여행사 36.8% vs 직접 15.3%, 기업 18.8% | 여행사 경유 39% vs 미경유 24.6%, 회사 경유 17.4% vs 미경유 38.2% |
| **특별 요청** | 요청 없음 47.8% vs 요청 있음 **21.8%** | lead_time 구간마다 요청 있는 예약이 절반 수준 |
| **과거 취소 이력** | 이력 있음 **91.7%** vs 없음 33.9% | 이력 보유 예약의 절반 이상이 단체 예약 |

**호텔별 차이:** 전체 취소의 4분의 3이 City Hotel에서 나옵니다. City Hotel은 단체·오프라인 여행사 취소율(68.9%, 42.9%)과 14박 이상 장기 예약 취소율(75.5%)이 높습니다. Resort Hotel은 직접 예약 비중이 높고, 성수기에 취소율이 가장 높습니다.

## 5. 제안: 호텔별 우선순위

| | City Hotel | Resort Hotel |
| --- | --- | --- |
| **1순위** | **포르투갈 단체·여행사 예약 관리** (취소율 76.6%): 단체 위약금, 여행사별 취소율로 배정 객실 조정, 미확정 객실 자동 반환 | **도착 30일·7일 전 예약 확인 메시지**: 직접 예약이 많아 직접 연락할 수 있음 |
| 근거 | 취소의 75%가 City Hotel이고, 그중 단체·여행사 취소율이 특히 높음 | 성수기 취소율이 가장 높음 |

**공통 제안**
- 90일 이상 전 예약(취소율 50.5%)에 확인 메시지와 보증금 적용
- 예약 직후 선호 층·조식·기념일을 안내해 특별 요청 유도(요청 없음 47.8%)
- 직접 예약 할인과 재방문 혜택으로 온라인 여행사 의존도 낮추기(36.8%)
- 과거 취소 이력(91.7%)을 최고 위험군으로 두는 **위험 등급** 매기기

## 6. 한계와 회고

- **상관이지 인과가 아닙니다.** 특별 요청이 취소를 줄이는 것이 아니라, 실제로 투숙할 고객이 요청을 하는 것일 수 있습니다. 그래서 "요청 유도"는 효과를 A/B 테스트로 확인해야 하는 가설입니다.
- **고객 ID가 없습니다.** "과거에 취소한 고객이 또 취소한다"를 같은 고객 단위로는 확인하지 못했습니다.
- **예측 모델은 만들지 않았습니다.** 위험 등급은 규칙 기반 제안입니다.
- **다시 한다면:**
  - 다섯 요인으로 취소 예측 모델을 만들고, 기간을 기준으로 데이터를 분할해 검증하겠습니다.
  - 초과 예약(오버부킹)은 예측이 충분히 정확할 때만 쓸 수 있으므로, 예측 오차를 얼마나 허용할지부터 정하겠습니다.
