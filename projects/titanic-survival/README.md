# 타이타닉 생존자 예측: 교차검증 1위 모델이 왜 리더보드에서 졌나

> **한 줄 요약:** 교차검증 1위 모델(0.847)이 Kaggle 리더보드에서는 성별 규칙 기준선(약 0.766)보다 낮은 0.761을 받았습니다. 오답을 분석해 과적합한 집단을 찾았고, 같은 모델의 복잡도만 낮춰 **0.787 (329/418)** 까지 올렸습니다.

| 항목 | 내용 |
| --- | --- |
| 과제 | 부트캠프 개인 과제 (Kaggle Titanic 대회) |
| 데이터 | Kaggle Titanic: train 891명 / test 418명 |
| 도구 | Python, pandas, scikit-learn (Pipeline, ColumnTransformer, GridSearchCV) |
| 노트북 | [`titanic_survival.ipynb`](./titanic_survival.ipynb) |

---

## 1. 문제: 무엇을 왜 풀려고 했나

- **입력:** 승객 정보(성별, 나이, 객실 등급, 요금, 가족 수, 티켓, 이름 등)
- **출력:** 생존 여부(0/1), 이진 분류
- **기준선:** "여성은 생존, 남성은 사망"이라는 성별 규칙만으로 train 교차검증 0.787, 리더보드 약 0.766을 얻습니다. 모델은 **이 기준선을 넘어야 의미가 있습니다.**

## 2. 기획: 목표와 제약

- **성공 기준:** 성별 규칙 기준선과 로지스틱 회귀 베이스라인(0.827)보다 높고, 분할을 바꿔도 순위가 유지되는 모델
- **제약:** train이 891명으로 작아, 검증 점수가 분할에 따라 크게 흔들립니다. 그래서 단일 5-fold 점수 대신 **반복 교차검증(5-fold × 3)** 으로 최종 후보를 다시 확인했습니다.
- **누수 방지:** 결측 처리와 인코딩을 모두 `Pipeline` 안에 넣어, fold마다 train 부분으로만 학습되게 했습니다.

## 3. 선택: 왜 이 방법을 골랐나

| 결정 | 이유 |
| --- | --- |
| 이름에서 **Title**(Mr, Mrs, Miss, Master, Rare) 추출 | 성별과 나이 정보를 함께 담음. 최종 모델의 특성 중요도 1위(Title_Mr 0.272) |
| 티켓 기반 변수 **TicketGroupSize, FarePerPerson** | 같은 티켓을 쓴 사람 수로 요금을 나누면 1인당 요금이 됨. Pclass와의 상관이 −0.549 → **−0.763**으로 강해짐 |
| Age 결측은 중앙값 + 결측 표시 열 | Title·Pclass별 중앙값도 실험함. 로지스틱 회귀는 0.823 → 0.830으로 올랐지만 랜덤 포레스트는 0.847 → 0.840으로 내려가 기존 방식을 유지 |
| 원-핫 인코딩 유지 | 순서 인코딩으로 바꾸자 0.813 → 0.806으로 하락 |

## 4. 실행: 어떻게 실험하고 비교했나

**① 기본 모델 비교 (5-fold)**

| 모델 | train | val | gap | 판단 |
| --- | --- | --- | --- | --- |
| 성별 규칙 (기준선) | — | 0.787 | — | |
| 로지스틱 회귀 | 0.841 | 0.827 | 0.014 | 안정적, 비선형 패턴에는 한계 |
| 결정트리 (제한 없음) | 0.989 | 0.787 | **0.202** | 심한 과적합, 기준선 수준 |
| 결정트리 (depth=4) | 0.847 | 0.817 | 0.030 | 깊이 제한만으로 크게 개선 |
| 랜덤 포레스트 (기본) | 0.989 | 0.813 | 0.176 | 과적합 |
| 그래디언트 부스팅 (기본) | 0.911 | 0.844 | 0.067 | 기본 설정 중 최고 |

**② 튜닝 → 티켓 변수 → 앙상블 → 반복 교차검증**

| 모델 | 처음 5-fold | 반복 5-fold × 3 |
| --- | --- | --- |
| **RF + 티켓 변수** | **0.855** | **0.847 ± 0.020** |
| Voting (A+RF2+GB2) | 0.849 | 0.844 ± 0.020 |
| GB + 티켓 변수 | 0.852 | 0.842 ± 0.022 |
| GB (기존 특성) | 0.850 | 0.834 ± 0.024 |

- 반복 평가에서 **모든 모델의 점수가 내려갔습니다.** 튜닝에 쓴 분할로 잰 점수가 낙관적이었다는 뜻입니다.
- 앙상블은 단독 모델을 넘지 못했습니다. 같은 특성을 쓴 RF와 GB는 예측 일치율이 0.96이라 같은 승객을 같이 틀렸습니다. 특성을 나누자 일치율은 0.707로 떨어졌지만, 이번에는 개별 모델이 너무 약했습니다(0.727).

## 5. 결과: 무엇이 되고 무엇이 안 됐나

**1차 제출 실패:** 교차검증 1위인 RF + 티켓 모델이 리더보드 **0.76076**을 받아, 성별 규칙 기준선보다도 낮았습니다.

**오답 분석:** 성별 규칙과 다르게 예측한 승객 58명을 집단별로 나눠 봤습니다.
- **3등석 여성 29명**을 사망으로 바꿨습니다. 이 집단은 train에서 생존율이 정확히 **0.50**입니다.
- 남자아이(Master)와 1등석 남성 28명은 생존으로 바꿨습니다.
- → `max_depth=8`의 깊은 트리가 결과가 반반인 집단을 요금·가족 수·티켓으로 잘게 나눠 **잡음을 외운 것**으로 판단했습니다.

**가설:** 성별 규칙에서 덜 과감하게 벗어나는 단순한 모델이 새 데이터에 더 잘 맞을 것이다.

| 제출 | 반복 CV | 성별 규칙과 다른 예측 | 리더보드 |
| --- | --- | --- | --- |
| **RF 얕게 (depth 5, leaf 4, sqrt)** | 0.830 | **21명** | **0.78708** (329/418) |
| 로지스틱 회귀 | 0.829 | 33명 | 0.77272 |
| 로지스틱 회귀 (특성 5개) | 0.826 | 24명 | 0.77033 |
| RF + 티켓 (1차 제출) | **0.847** | 58명 | 0.76076 |
| GB + 티켓 | 0.842 | 45명 | 0.74880 |

- **교차검증 순위와 리더보드 순위가 거의 반대**였습니다.
- 성별 규칙에서 많이 벗어날수록 대체로 점수가 낮았습니다. 완전히 비례하지는 않습니다.
- 같은 RF를 얕게 만들자 **11명을 더 맞혔습니다**(318 → 329).

## 6. 한계와 회고

- **리더보드로 최종 모델을 골랐습니다.** 다섯 개 제출 중 최고 점수를 골랐으므로, 0.78708은 새 데이터에서 기대할 성능보다 **낙관적인 추정**입니다. 같은 이유로 리더보드를 반복 튜닝에 쓰면 이번에 겪은 문제를 리더보드에서 다시 겪게 됩니다.
- **다시 한다면:**
  - 처음부터 "성별 규칙과 다르게 예측한 승객"을 검증 단계의 진단 지표로 넣어, 제출 전에 과적합 집단을 확인하겠습니다.
  - 트리 복잡도(depth, leaf)를 반복 교차검증으로 고르고, 리더보드는 마지막 한 번만 확인하겠습니다.
- **배운 점:** train 안의 평가만으로는 train과 test의 차이를 다 볼 수 없습니다. 점수 하나보다 **어떤 집단에서 예측이 바뀌었는지**를 보는 것이 원인을 찾는 데 더 쓸모 있었습니다.
