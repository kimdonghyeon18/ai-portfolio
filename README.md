## 정리 원칙

- 모든 수치는 노트북에서 직접 실행해 얻은 값입니다.
- 결과와 함께 **한계와 다음 실험**을 적습니다.
- 데이터 파일은 각 출처의 이용 약관에 따라 저장소에 포함하지 않았습니다.
