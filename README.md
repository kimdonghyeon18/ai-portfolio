# AI 엔지니어 포트폴리오

데이터 분석과 머신러닝에서 시작해 딥러닝과 컴퓨터비전까지 배운 과정을 기록하는 저장소입니다.
각 프로젝트 README는 **문제 → 기획 → 선택 → 실행 → 결과 → 회고** 순서로 정리했습니다. 무엇을 만들었는지보다 **왜 그렇게 판단했고 어떻게 확인했는지**를 남기는 것이 목표입니다.
